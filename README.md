# Profile Card

A simple, responsive profile card with a **Light** and **Dark** theme toggle built using HTML, CSS, and JavaScript.

**Live Link:** https://shakibcodes.github.io/profile-card/

## Features

- Dark mode (default) and Light mode toggle
- Theme-based profile avatar switching
- Social media links and a "Get in touch" button

## File Structure

```
profile-card/
├── index.html      # Main HTML structure
├── style.css       # Card styling and light/dark themes
├── script.js       # Theme toggle functions (setLight & setDark)
├── dark.png        # Dark mode profile image
├── light.png       # Light mode profile image
└── icons/          # Email and social media SVG icons
    ├── email.svg
    ├── instagram.svg
    ├── tiktok.svg
    ├── twitter.svg
    └── website.svg
```
